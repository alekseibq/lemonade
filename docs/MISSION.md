# Mission

Lemonade RL Lab — локальный исследовательский инструмент для практики RL на
проверяемой экономической среде. MVP доказывает: seeded headless-эпизод
воспроизводим, Gymnasium-агент завершает его, а reward экономически согласован.

Граница текущего MVP: правила `lemonade-stand/v1`, базовые политики и оценка.
Нет БД, HTTP, браузера, облачного обучения и обобщённого игрового фреймворка.
