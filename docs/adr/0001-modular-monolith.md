# ADR 0001: modular monolith and in-process training

Status: accepted.

Выбран один Python-проект с отдельными модулями и CLI. Нагрузка локальная,
симуляция мала, а разделение на сервисы добавило бы задержки и усложнило
воспроизводимость. Training будет отдельной CLI-командой, но использует среду
in-process. Контейнеры отложены: virtualenv достаточно для текущего локального MVP.
