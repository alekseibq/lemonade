# Lemonade RL Lab

Локальная воспроизводимая лаборатория Reinforcement Learning. Первый сценарий —
«Лимонадный киоск»: агент назначает цену и объём производства в течение 10 дней.

Текущий срез реализует чистое игровое ядро, Gymnasium-совместимую среду и baseline-
агентов. Веб-интерфейс, обучение PPO и HTTP API пока не реализованы.

## Quick start

Требуется Python 3.11+.

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
pytest
lemonade --policy rule --seed 42
```

Дополнительно для будущей RL-итерации: `pip install -e '.[dev,rl]'`.

## Rules v1

- Стартовый капитал 2 000 ₽, себестоимость 10 ₽ за стакан, 10 дней в эпизоде.
- Действие: `price ∈ [0,99]`, `requested_production ∈ [0,200]`.
- Если денег не хватает, выпуск сокращается до `floor(capital / cost)`; действие и
  фактический выпуск фиксируются в результате.
- Непроданные стаканы списываются. Reward равен дневной прибыли, поэтому сумма
  reward равна изменению капитала за эпизод.
- Погода и шум спроса создаются целиком при `reset(seed=...)`, поэтому одни и те
  же seed дают одинаковый внешний сценарий вне зависимости от policy.
